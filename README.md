# Roblox Teleport Script

A simple teleport script for Roblox.

## Features

- Press P to enable/disable
- Red teleport marker
- Left click to teleport
- Mobile support

## How to Use

### PC

1. Execute the script in your executor
2. Press **P** to activate
3. Move the mouse pointer and **left-click** to teleport
4. Press **P** again to deactivate

### Mobile

1. Use the **Activate** and **Deactivate** buttons in the mobile window to enable or disable teleport mode
2. Tap the screen to place the red marker
3. Press **TELEPORT** to go to the selected location
4. Use the small red button to clear the marker
